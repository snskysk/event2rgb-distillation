# `lists/` — download the large index files from Google Drive

These files are index / TSV files too large to store in this repository, so they
are hosted on Google Drive. Download the folder contents and place them **here**
(keep the same filenames):

- **Drive folder:** https://drive.google.com/drive/folders/1h7uJ58eVKdKBAlSgZERnJbiJPEN3e9dy?usp=sharing
- **Files restored:** `paired_train.tsv`, `paired_val.tsv`, `imagenet_train_ratio1.0_seed1.txt` (~256 MB total)

Then update the absolute data paths inside `paired_train.tsv` to point at your
local ImageNet / N-ImageNet trees. See the top-level `README.md`
("Auxiliary Data Files" and Part 2 "Dataset Preparation") for details.
